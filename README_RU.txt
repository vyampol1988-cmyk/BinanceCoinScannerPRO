СКАНЕР МОНЕТ BINANCE — только анализ, без торговли

Что делает:
- Сканирует ликвидные спотовые пары USDT на Binance.
- Ранжирует монеты по импульсу цены, тренду EMA, росту объёма и RSI.
- Отдельно показывает монеты из вручную составленного списка мемкоинов.
- Сохраняет результаты в CSV-файл в папке scanner_results.

Важно:
- Программа НЕ покупает и НЕ продаёт криптовалюту.
- Баллы — это эвристический рейтинг, а не прогноз и не гарантия прибыли.
- Список мемкоинов не является официальной классификацией Binance.
- Анализ не выявляет все мошеннические проекты, разблокировки токенов или риски новостей.

Запуск на Windows 10/11:
1. Установи Python 3.10 или новее: https://www.python.org/downloads/
   При установке включи Add Python to PATH.
2. Распакуй архив в отдельную папку.
3. Открой эту папку, нажми на адресную строку Проводника, введи cmd и нажми Enter.
4. Выполни команды:
   python -m pip install requests
   python binance_coin_scanner.py
   Если команда python не работает, используй py вместо python.
5. Посмотри таблицу в окне командной строки и CSV-отчёт в папке scanner_results.

API-ключ Binance не нужен. Программа использует только публичные рыночные данные.
